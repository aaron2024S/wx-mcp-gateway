微信 MCP 网关

微信里一句话，
家里的设备就动了

不装 App、不开端口、不做内网穿透。
这个网关把微信消息接到你自己的各个应用上。

  • 微信直连扫码绑定机器人，长轮询收发；链路纯出站，不需要公网 IP
  • 接任意应用只要对方是 MCP server，填个地址就能用，不用改代码
  • 工具自动发现读对方的 tools/list 建索引，中文说法也能对上号
  • 动手之前先问一句高危操作二次确认，网关自己还有一道硬上限
  • AI 可有可无本地词表答不上来才问模型；没有 API key 照样能用

登录只要一个密码：scrypt 哈希落盘、HttpOnly 会话、连续失败锁定。

网关不联网、也不存明文密码，所以没有"找回"，只能重置：

  1. 在 NAS 的文件管理里打开这个容器的数据目录（compose 里挂载的 data）。
  2. 删掉目录里的 auth.json。
  3. 重启容器，再打开页面就会回到"设置密码"。

重置后所有设备上已有的登录会一并失效。
