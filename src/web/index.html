添加应用

填写连接信息并测试

会出现在工具名里：mail.list_messages。定了就别改，改了旧日志对不上。
用户不会说 id，会这么说。这个字段比名字更影响命中率。
应用自己要提供 HTTP 的 MCP 端点（一般是 /mcp）。容器之间用服务名，不要写 localhost；端口是容器内端口。
保存后只显示「已设置」，永远不会回传给前端。
这是网关的硬上限，应用自己声明的等级不能突破它。
